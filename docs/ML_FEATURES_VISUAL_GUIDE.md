## 💻 What Code Looks Like

### Simple Example: Outfit Recommendation

```typescript
// Backend - Get recommendations
const occasion = "business meeting";
const userClothes = await getClothes(userId);
const recommendations = await recommendOutfits(occasion, userClothes);

// Response:
{
  occasion: "business meeting",
  recommendations: [
    { item: "Blue Blazer", matchScore: 94, reason: "Perfect match" },
    { item: "White Shirt", matchScore: 92, reason: "Perfect match" }
  ]
}
```

```typescript
// Frontend - Display recommendations
<button onClick={() => getRecommendations("business meeting")}>
  Get Business Outfit
</button>

{recommendations.map(rec => (
  <div>
    <img src={rec.item.image} />
    <h3>{rec.item.name}</h3>
    <p>Match: {rec.matchScore}%</p>
    <p>{rec.reason}</p>
  </div>
))}
```
